# Agent instructions for GQE

Use the guidance relevant to the current task:

- [C++ and CUDA](docs/agent-guidance/cpp-cuda.md) before modifying C++ or CUDA
  code.
- [Build, test, and tooling](docs/agent-guidance/build-test.md) when configuring,
  building, testing, or running repository tooling.
- [Merge requests](docs/agent-guidance/merge-requests.md) before creating commits,
  branches, or merge request content.
- [Benchmarking](docs/agent-guidance/benchmarking.md) when measuring or making
  performance claims.
- [`README.md`](README.md) when running GQE or changing runtime configuration,
  environment variables, or user-facing behavior.
- [Engine facts](docs/agent-guidance/engine-facts.md) when working on storage,
  compression, Flight SQL, logging, or memory-footprint measurement.

Read [`CONTRIBUTING.md`](CONTRIBUTING.md) before creating or modifying
repository files, including its copyright and license-header requirements. It
also contains the canonical repository setup, build, test, and contribution
instructions; prefer those instructions over duplicating them here.
